# Посылки Outliving v1.0 (Premises)

> **Как читать этот документ.** Посылки — это гипотезы, прошедшие сегодняшний
> брейншторм, от которых Марк **не хочет отказываться**. Любая новая идея
> проверяется на конфликт с ними. Если идея конфликтует — сначала знать об этом,
> потом решать.
>
> Статусы: ✅ **утверждено** (ядро, не трогать) · 🟡 **черновик** (направление
> согласовано, детали открыты) · ❌ **отброшено** (зафиксировано, чтобы не
> возвращаться)

## БОЛЬШИЕ посылки (макро-уровень)

| # | Посылка | Статус |
|---|---|---|
| B1 | **Гибридная графика: сглаженный воксельный мир + low-poly персонажи. Тёмная и мрачная.** Террайн и постройки — воксельные со сглаживанием (Marching Cubes) для процедурной генерации и читаемости ландшафта (B6). Персонажи, враги и ключевые предметы — low-poly стилизованные (~500–2000 tris) со скелетной анимацией для читаемости телеграфов (M4) и атмосферы тёмного славянского фэнтези (B7). Референсы: Vintage Story (мир) + Valheim (персонажи, освещение). Решение принято по результатам анализа визуальных стилей (см. `design/09-visual-style-direction.md`). | ✅ |
| B2 | **Аудитория 13–14 лет** — мягкая отсылка, не жёсткий таргет. Инди-подход: «честная суровость + увлекательный геймплей» важнее попадания в аудиторию | ✅ |
| B3 | **«Честная суровость»**: противника можно прочитать (телеграфы), и он может прочитать тебя. Никакого обмана механик | ✅ |
| B4 | **Нет автоскейлинга врагов.** Враг всегда такой, какой он есть. Усиление — только мировыми событиями и **всегда визуально отражено** | ✅ |
| B5 | **Прогрессия через мир и мастерство, а не гринд.** Стойки — у учителей в диких зонах, магия — у алтарей, оружие — за риск. География = прокачка | ✅ |
| B6 | **«Говорящий визуал»**: локация отражает угрозу, всё читается с первого взгляда. Центр Лугов зелёный → кромка пожухлая → болото тихое, но опасное | ✅ |
| B7 | **Сеттинг: тёмное славянское фэнтези по «Трое из Леса» Никитина** — невры, Лес как живая сущность, болота с нечистью (упыри, водяницы, кикиморы), дрягва, поляне | ✅ |
| B8 | **Враги-нежить — гуманоидные твари, а не люди и не абстрактные духи.** Как утопцы из Ведьмака. Мотивация живая: голод, территория, страх (для людей) / природа нежити (для тварей) | ✅ |
| B9 | **Solo-first + опциональный кооп/сессии.** Мультиплеер — слой, а не фундамент. Сессии 2–4–6, данжи в удалённых зонах | ✅ |
| B10 | **Мирный путь валиден**: пекарь, кузнец, алхимик — полноценные роли, кормящие бойцов. Инструменты для развлечения, а не предписание | ✅ |
| B11 | **Живой мир по логике выживания**: NPC отступают при потерях, фракции без меню (S.T.A.L.K.E.R.-style), биомы сдвигаются от активности игроков, мир помнит разрушения | 🟡 |
| B12 | **DBNO — физическая взаимопомощь**: раненого несут на плечах (без бега и двуручного), таймер кровотечения, точки спасения | 🟡 |
| B13 | **Петля = путешествие, а не вылазка**: движение от безопасной зоны к безопасной зоне по сюжетной нити (Gothic-стиль), а не «хаб → портал → хаб» | ✅ |

## МАЛЫЕ посылки (микро-уровень)

### Бой
| # | Посылка | Статус |
|---|---|---|
| M1 | Формула урона: `Урон = max(1, Атака − Броня)` — жёсткий порог брони (прототип, может корректироваться) | 🟡 |
| M2 | Три слоя силы: опыт игрока (тайминги) / навыки персонажа (стойки) / свойства оружия (тип урона, длина, масса) | ✅ |
| M3 | Характеристика «Воля» — защита от ментала, не связана с маной, прокачивается выживанием на грани | 🟡 |
| M4 | Каждая атака врага: **Telegraph → Attack → Recovery**. Никаких instant-hit без телеграфа | ✅ |
| M5 | Реакции игрока: уклонение (всегда работает), блок (стамина), парирование (высокий риск, riposte), контратака | 🟡 |
| M6 | Стойки меняют стиль, а не обязательная прокачка: «Железный хват» (блок не пробивается разгоном), «Танец клинка» (+окно парирования) | 🟡 |
| M7 | Прогрессия сложности Лугов: Волк → Волк+Волк → Утопец → Кабан → Кабан+Утопцы. Каждый враг = одно новое правило | ✅ |
| M8 | Утопец — первая нежить: вода = опасная зона, тина замедляет, захват тащит в болото | 🟡 |
| M9 | Волк при <30% HP убегает → добить или отпустить = решение с последствиями | 🟡 |

## ❌ Отброшено сегодня (не возвращаться)

| Идея | Почему отброшена |
|---|---|
| Название «The End and the Death» | Прямое название финальной книги Warhammer 40k (Абнетт). Юридические и ассоциативные риски |
| Заблудший Дух как враг Лугов | Абстрактный дух не в духе Никитина. Враги — живые твари/люди с мотивацией |
| Лесной дикарь (человек) как болотный враг | Марк имел в виду **гуманоидную нежить** (утопец/упырь), а не людей |
| Портал-телепорт в хаб (Diablo-стиль) | Противоречит петле «путешествие» (B13). Возврат — пешком через мир |

## ⚠️ Стыки и потенциальные противоречия (важно знать)

| # | Стык | Решение / статус |
|---|---|---|---|
| C1 | **6v6 PvP (M17) vs честность без скейлинга (B4)** | ✅ **Решено**: противоречия нет. Меньше правил — проще соблюдать. Никакого скейлинга нигде, включая PvP: встречаются игроки разной силы — это честно и по правилам мира |
| C2 | **«Мир помнит разрушения» (B11) vs восстановление мира** | 🟡 Если память вечная — мир деградирует до пустыни. Если восстанавливается — «память» конечна. Нужен баланс: время деградации/восстановления |
| C3 | **«Честная суровость» (B3) vs аудитория 13–14 (B2)** | ✅ **Решено**: инди-продукт, в аудиторию не целимся жёстко. Честная суровость + увлекательный геймплей — сами по себе. Тайминги решаются на прототипе |
| C4 | **Мирный путь без гринда (B10) vs крафт из редких ресурсов (M11)** | ✅ **Решено**: у мирного игрока есть 4 пути к редким ресурсам: (1) купить за валюту от продажи своей еды; (2) оказать услугу NPC — дешевле продают; (3) найти в мире (в т.ч. в «живом» мире — разорённая деревня, остатки); (4) живой обмен/бартер |
| C5 | **«Говорящий визуал» (B6) vs скрытые угрозы** | 🟡 Если враг прячется и не виден — нарушение принципа читаемости. Любая угроза должна быть считана с окружения (заводь, пузыри, пожухлая трава) |
| C6 | **DBNO (B12) + смерть (M14) в коопе** | 🟡 Если раненого несут — что с его незабаненным лутом при провале? Не определён стык «перенос груза + DBNO» |
| C7 | **Shared Persistence и чужие порталы/следы** | 🟡 Видят ли игроки следы чужих групп? Если да — «мир помнит» получает социальный слой; если нет — проще, но менее живо |
| C8 | **Фаст-тревел (дирижабли, v0.1) vs путешествие пешком (B13)** | 🟡 Дирижабли не запрещены, но должны быть событием/ресурсом, а не кнопкой. Иначе разрушают «честность пути» |

## Как проверять новые идеи (чек-лист)

1. Прочитать B1–B13. Идея ломает хотя бы одну ✅? → **СТОП, сначала обсудить**.
2. Идея в зоне 🟡 (детали открыты)? → Ок, уточняет, не конфликтует.
3. Идея = отброшенное (❌)? → Только с явным решением «переоткрыть», с причиной.
4. Идея трогает стык C1–C8? → Отметить, какой стык, и решить осознанно.
