# Звук как механика: Аудио-телеграфы и подсказки мира v1.0

> 📐 **Gothic-принцип.** Игрок читает мир ушами — не меньше, чем глазами.
> Звук не декор. Звук — полноценный телеграф (M4), равный визуальной
> анимации. Каждая опасность имеет аудио-подпись. Тишина — тоже подпись.
>
> Аудио-телеграф — это Sekiro-очередь: звук, который игрок учится
> распознавать **раньше**, чем увидит врага. Звук учит читать опасность
> ДО визуального контакта. Для аудитории 13–14: звук = читаемость,
> не страшилка (B2). Никаких резких скримеров, только информативные
> предупреждения.

---

## 0. Контекст и проблема

### 0.1. Что уже спроектировано

В существующих дизайн-документах звук упоминается разрозненно:

| Документ | Что описано | Статус |
|---|---|---|
| `[[combat-design]]` §4–10 | Звуковые телеграфы врагов (бульканье утопца, утробный звук Громилы, визг Выползней) | Разрозненно, не система |
| `[[meadows-biome-design]]` §1 | Звуковые профили зон Лугов (птицы → тишина → бульканье) | Есть, но без правил |
| `[[bog-biome-design]]` §1, §5 | Звуковые профили зон Болота, лягушки-индикаторы, тишина, крик цапли, вороны | Есть, без системы |
| `[[tier3-biome-design]]` §2, §6 | Звук падающего дерева (Telegraph 1.5с), вой волков, замолкание филина, цоканье белки | Разрозненно |
| `[[odyssey-divine-factions]]` §6 | Знамения (гром, шёпот, эхо), погода как UI | Частично, без аудио-слоя |
| `[[combat-design]]` §14 | Открытый вопрос: «Нужен ли звук-предупреждение к каждому телеграфу?» | ❓ Не отвечен |

### 0.2. Что спроектировать

**Целостную систему аудио-телеграфов**, пронизывающую все слои игры:

1. **Боевой слой** — аудио-телеграф на каждую атаку каждого врага
2. **Биомный слой** — звуковой профиль зоны, тишина как индикатор, звуки-предвестники
3. **Божественный слой** — аудио-знамения богов (шёпот, гром, треск льда, музыка земли)
4. **Слой нейтралов** — звуки живности как «радар» опасности

## 1. Принципы аудио-телеграфа

### 1.1. Золотые правила

| # | Правило | Обоснование |
|---|---|---|
| **P1** | Каждая опасность имеет аудио-подпись. Если враг/ловушка не издаёт звук — это **осознанное дизайн-решение**, а не пропуск | Полнота системы |
| **P2** | Звук всегда **предшествует** визуальному контакту. Сначала слышишь → потом видишь | Sekiro-философия: «читай ушами» |
| **P3** | Звук = телеграф в фазе Telegraph. Звук атаки = активная фаза Attack. Тишина = Recovery или засада | Привязка к M4 (Telegraph→Attack→Recovery) |
| **P4** | Дистанция слышимости задана для каждого звука. Игрок понимает: «этот треск — в 30 метрах, а этот — прямо за спиной» | Пространственная читаемость |
| **P5** | Звук не спамит. Паузы, очерёдность, приоритеты. Не больше 2–3 информативных звуков одновременно | Когнитивная нагрузка 13–14 лет |
| **P6** | Никаких резких скримеров. Громкость растёт плавно, звук всегда информативен, а не пугает | B2 (аудитория 13–14) |
| **P7** | Звуковой профиль биома описан градиентом: от безопасного к опасному | B6 («говорящий визуал» → «говорящий звук») |

### 1.2. Три типа аудио-сигналов

```
┌──────────────────────────────────────────────────────────────┐
│                     АУДИО-СИГНАЛЫ                            │
├─────────────────┬──────────────────┬─────────────────────────┤
│  ТЕЛЕГРАФ        │  ИНДИКАТОР        │  ПРОФИЛЬ                │
│  (активный)      │  (пассивный)      │  (фоновый)              │
├─────────────────┼──────────────────┼─────────────────────────┤
│ Оповещает о     │ Сообщает о        │ Создаёт атмосферу       │
│ КОНКРЕТНОЙ      │ СОСТОЯНИИ         │ места. Не несёт         │
│ атаке/действии.  │ окружения.        │ прямой угрозы.          │
│ Привязан к фазе  │ Работает всегда.  │ Меняется с градиентом   │
│ Telegraph M4.    │ Пример: лягушки   │ биома.                  │
│                  │ квакают =         │ Пример: ветер в траве,  │
│ Пример: «треск   │ безопасно.        │ комариный звон.         │
│ перед падением   │                   │                         │
│ дерева»          │                   │                         │
└─────────────────┴──────────────────┴─────────────────────────┘
```

**Правило приоритета:** Телеграф > Индикатор > Профиль. Если звучит аудио-телеграф врага, фоновые звуки приглушаются на 30% — игрок не должен прослушать угрозу из-за шума.

| ❄️ **Морена** (мороз) | Наступление холода | Тихий треск льда на траве. Пар изо рта игрока. Ветер становится ледяным. | 25м | 1.0–1.5с | «Треск льда = вода замёрзнет. Не ходи по корке.» |
| | Замёрзший | Хруст льда (тело разламывает лёд при движении) | 15м | 1.0с | «Хруст льда = замёрзший идёт. Бей огнём или дроби.» |
| 🌬️ **Стрибог** (ветер) | Шквал | Внезапная тишина (затишье). Листья замирают. Пыль поднимается столбом. | 30м | 1.0с | «Затишье + пыль = сейчас шквал. Укройся за деревом.» |
| 🔥 **Сварог** (алтарь) | Активация алтаря | Низкий гул металла + треск разгорающегося пламени | 20м | 2.0с | «Гул металла = кузня Сварога. Здесь можно укрыться.» |

### 2.6. Враги/существа с **осознанным отсутствием звука**

Не все опасности телеграфируют звуком. Некоторые — **тишиной**, и это осознанное дизайн-решение:

| Враг / Опасность | Почему без звука | Что взамен |
|---|---|---|
| 🕷️ **Паук-пряха** | Нейтрален. Не нападает первым. Звук = агрессия — не нужен | Паутина видна: блестит в свете факела, глухой стук при касании |
| 🕸️ **Паутина-ловушка** | Липкая, бесшумная. Угроза — в невнимательности | Блестит в свете. В темноте — только фонарь/факел |
| 🐍 **Уж болотный** | Не агрессивен. Предупреждает о крупном хищнике своим поведением | Заметен визуально: греется на камне |
| 🔥 **Блуждающий огонёк** | Не опасен напрямую. Приводит к Водянице — тихо | Визуальный: зеленоватый шар. Нельзя идти за ним >3 мин |
| 🕳️ **Трясина** | Засасывает беззвучно. Индикатор — визуальный (ряска, отсутствие деревьев) | Визуальные индикаторы (см. [[bog-biome-design]] §6) |
| 🍄 **Гриб-дождевик** | Беззвучен, пока не наступишь. Индикатор — визуальный: белый шар | Визуальный: видно на земле |
| 🪵 **Гнилые мостки** | Скрипят ТОЛЬКО при беге. При ходьбе — беззвучны | Визуальное состояние досок (свежие vs тёмные) |
| 🏚️ **Засада Громилы** | Громила стоит в воде неподвижно. Без звука — пока игрок близко | Индикаторы: отсутствие лягушек, воронов, водомерок. Пузыри со дна |

## 3. Звуковой профиль биомов: градиент опасности

Каждый биом имеет **три звуковые зоны** — градиент от безопасной к смертельно опасной. Игрок учится читать биом по шуму.

### 3.1. Луга (Tier 1)

| Зона | Звуковой профиль | Что означает |
|---|---|---|
| 🌿 **Центр** (0–300м) | Ветер в высокой траве. Жаворонки, овсянки. Далёкий стук топора (деревня). Жужжание пчёл. Кузнечики. | Безопасно. Люди рядом. Еда рядом. |
| 🌾 **Середина** (300–600м) | Меньше птиц. Сверчки. Ветер гудит в камнях башни. Далёкий волчий вой (редко). | Опасность на горизонте. Волки близко. |
| 🟤 **Кромка** (600м+) | **Тишина.** Птиц нет. Комариный звон. Бульканье воды. Влажный шлепок в тумане. | Болото рядом. Утопцы. Опасно. |

**Ключевой индикатор Лугов:** птицы. Поют = безопасно. Замолкают = хищник в радиусе 40м.

### 3.2. Болото (Tier 2)

| Зона | Звуковой профиль | Что означает |
|---|---|---|
| 🟤 **Край** (0–400м) | Хлюпанье под ногами. Редкий крик ворона. Комариный звон. Далёкое бульканье. Лягушки квакают. | Условно безопасно. Лагерь дрягвы рядом. |
| 🟫 **Гнилые Топи** (400–800м) | **Тишина.** Ни комаров, ни ворон. Только вода: капля за каплей. Иногда — влажный шлепок. Шёпот? Показалось. Вой ветра в мёртвых деревьях. | Опасно. Громилы. Ветераны. Лягушки молчат = рядом хищник. |
| ⬛ **Сердце** (800м+) | **Ничего.** Абсолютная тишина. Давит на уши. Потом — далёкий женский плач. Водяница. | Смертельно опасно. Босс. Не ходи без подготовки. |

**Ключевые индикаторы Болота:**
- Лягушки квакают = безопасно. Замолкают = Громила/Ветеран в 25м.
- Цапля кричит (громко) = здесь кто-то есть (50м).
- Ворон каркает = труп/бой рядом. 4+ ворона = засада.
- Водомерки на воде = утопца нет. Нет водомерок = под водой кто-то.
- Бульканье = пузыри со дна → утопец.

### 3.3. Тёмный Лес (Tier 3)

| Зона | Звуковой профиль | Что означает |
|---|---|---|
| 🌲 **Опушка** (0–400м) | Дятлы, кукушка. Треск веток под ногами. Ветер в кронах (высоко). Шелест листвы. | Условно безопасно. Лагерь Диких невров рядом. |
| 🌲🌲 **Середина** (400–800м) | **Тихо.** Птиц меньше. Скрип стволов. Далёкий волчий вой. Близкий треск сучьев (кто-то идёт?). | Опасно. Одичавшие рядом. |
| 🌲🌲🌲 **Чаща** (800м+) | **Тишина.** Даже ветра нет. Только пульс игрока и тяжёлое дыхание. Низкий утробный рык. | Смертельно опасно. Вожак. Капище. |

**Ключевые индикаторы Леса:**
- Филин ухает = безопасно. Замолкает = Одичавший в 20м.
- Белка цокает = игрока заметили. Тишина после цоканья = белка убежала — рядом хищник.
- Олень замер и смотрит = Вожак или Леший в 50м.
- Вой волков на закате = стая собирается. Ищи укрытие.
- Треск за 1.5с = падающее дерево. Отходи.
- Муравьи бегут в одном направлении = там вода.

## 4. Божественные аудио-знамения

Боги не говорят словами. Их присутствие слышно в мире. Игрок учится распознавать божественный аудио-слой — как погоду, но ушами.

### 4.1. Активные боги

| Бог | Доброе знамение (растёт внимание) | Злое знамение (внимание падает / бог недоволен) |
|---|---|---|
| 🐺 **Велес** | Волк воет раз в ночь — одинокий, мелодичный. Змея шипит негромко, не нападая. Ветер приносит запах мокрой шерсти. **Олег: слышит шёпот посланников** (неразборчивые слова, как эхо в пещере) | Сова кричит днём. Змея шипит с порога (враждебный звук). Мёртвая тишина в лесу — Велес отвернулся |
| ⚡ **Перун** | Гром в ясном небе — одинокий, дальний. Дуб роняет жёлудь (глухой стук). Оружие звенит само по себе (чистый металлический звон). **Таргитай: слышит ритм боя** — ускоренный пульс в ушах | Дуб за спиной игрока расщеплён молнией. Гроза без дождя (сухие раскаты). Оружие тускнеет — звук становится глухим |
| ❄️ **Морена** | Тихий треск льда под ногами (даже летом). Пар изо рта — слышно дыхание. Ветер завывает в костях. **Мрак: слышит вой Белого Волка** в полнолуние | Иней на оружии: холодный звон. Птицы замолкают и падают (шлепок). Вода в луже замерзает с громким треском. Собаки воют без причины |
| 🌾 **Мокошь** | Пшеница шелестит под ногами. Женский смех вдали (ветер?). Пчёлы гудят густо, сыто. **Таргитай: слышит «музыку земли»** — низкий ритмичный гул, как сердцебиение почвы | Трава жухнет с сухим шорохом. Хлеб трескается (сухой хруст). Колосья пустые — ветер не шелестит в них. Тишина на полях |
| 🔨 **Сварог** (малый) | Искры от костра трещат громко. Наковальня звенит вдали (даже если нет кузни). Молот бьёт по металлу — чистый, ритмичный звон | Костер дымит, шипит. Искры летят в лицо (треск). Металл тускнеет — звук глохнет |
| 🌬️ **Стрибог** (малый) | Ветер меняет направление: слышно, как листья поворачиваются. Попутный ветер воет в ушах — приятно. Птицы поют громче | Ветер всегда встречный — воет в лицо. Пыль скрипит на зубах. Листья хлещут по лицу |
| 💧 **Дана** (малый) | Вода в луже идёт кругами (тихий плеск). Рыба выпрыгивает (всплеск). Ручей журчит мелодичнее | Вода мутнеет — бульканье становится глухим. Рыба всплывает брюхом (тишина). Ручей пересыхает — только сухой треск земли |

### 4.2. Божественный шёпот (особая механика)

Некоторые архетипы **слышат божественное** через пассивные системы:

| Архетип | Что слышит | Условие |
|---|---|---|
| 📜 **Олег** | **Шёпот посланников Велеса** — неразборчивые слова на грани слышимости. Как эхо в пещере. Подсказывает: тип следующей атаки врага, направление | Высокое внимание Велеса + уровень «Знающий»+. Усиливается у алтарей и в пещерах |
| 📜 **Олег** | **Шёпот Мокоши** — ритмичный, как веретено. Нити судьбы «звучат»: Олег слышит натяжение/обрыв. Предупреждает о смертельной опасности за 2 сек | Высокое внимание Мокоши + уровень «Волхв» |
| 🎵 **Таргитай** | **«Музыка земли»** — низкий ритмичный гул, как сердцебиение. Меняет темп: спокойный = безопасная тропа; ускоренный = опасность; затихает = тупик | Покровительство Мокоши. Работает в лесу/болоте. |
| 💪 **Мрак** | **Вой Белого Волка** — одинокий, далёкий. Слышен только в полнолуние. Указывает направление к Волчьему алтарю. В бою — вой предупреждает о засаде за 5 сек | Естественная способность. Усиливается при высоком внимании Велеса |

## 5. Правила громкости, дистанции и пауз

### 5.1. Дистанция слышимости

| Тип звука | Радиус | Пример |
|---|---|---|
| **Ближний** | 0–5м | Дыхание врага, шаги крадущегося Одичавшего, шорох Выползня, прилипание |
| **Средний** | 5–20м | Бульканье утопца, хрюканье кабана, визг Выползня, рычание Одичавшего, хруст льда |
| **Дальний** | 20–40м | Вой волка, крик цапли, скрежет Ветерана, утробный звук Громилы, гром Перуна, треск падающего дерева |
| **Очень дальний** | 40–80м | Вой Вожака, плач Водяницы, раскат грома, Зов Леса (Леший) |

### 5.2. Громкость: правило трёх слоёв

```
┌─────────────────────────────────────────────────┐
│  Слой 1: ТЕЛЕГРАФЫ (100% громкости)             │
│  Звук атаки врага, падающего дерева, молнии.    │
│  Всегда слышен отчётливо. Не маскируется.        │
├─────────────────────────────────────────────────┤
│  Слой 2: ИНДИКАТОРЫ (70% громкости)             │
│  Лягушки, птицы, вороны, цоканье белки,          │
│  шаги врага. Приглушаются, если звучит телеграф. │
├─────────────────────────────────────────────────┤
│  Слой 3: ПРОФИЛЬ (40% громкости)                 │
│  Ветер, комары, дождь, эхо, скрип деревьев.     │
│  Приглушается до 20% при телеграфе.              │
└─────────────────────────────────────────────────┘
```

**Правило дублирования:** если два врага издают одинаковый телеграф одновременно, звук не суммируется — остаётся на 100%. Приоритет: босс > элита > рядовой.

### 5.3. Паузы и анти-спам

| Правило | Значение |
|---|---|
| **Минимальная пауза** между аудио-телеграфами | 0.8 сек. Два звука не накладываются |
| **Максимум одновременных** информативных звуков | 3 (из них не более 2 — телеграфы) |
| **Затухание фона** при телеграфе | −30% к громкости слоёв 2 и 3 на время телеграфа + атаки |
| **Босс-телеграф** всегда имеет приоритет | Все остальные звуки −50% на время телеграфа босса |
| **Звуки нейтралов** (лягушки, птицы, белки) | Срабатывают не чаще 1 раза в 3 сек. Не спамят |
| **Вой волков** | Не чаще 1 раза в 30 сек. После боя — пауза 60 сек |
| **Биомная тишина** (Сердце Болота, Чаща) | Профиль сам по себе является паузой: там почти нет фоновых звуков. Тишина — тоже «звук» |

### 5.4. Пространственный звук

- Звук позиционируется в 3D: игрок поворачивает камеру — слышит направление.
- Звук слева/справа/сзади имеет разный баланс каналов. Волк за спиной ≠ волк спереди.
- Эхо и реверберация зависят от окружения: в пещере — гуляет эхо 0.5с, в поле — сухой звук.
- В тумане: высокие частоты глушатся, низкие — проходят. Игрок слышит шаги Громилы (низкий бас), но не слышит комаров.
- Под водой: все звуки глухие, сдавленные. Звук утопца — единственный чёткий.
- В грозу: гром маскирует звуки шагов (и своих, и врагов). Каждый раскат — окно скрытности.

## 6. Звук и мирный путь

Мирный игрок (B10) использует звук иначе, чем боевой:

| Ситуация | Мирный игрок слышит | Что делает |
|---|---|---|
| Подход к заводи | Бульканье = утопец. Тишина = чисто | Обходит заводь, забрасывает удочку с другой стороны |
| Сбор грибов в Лесу | Цоканье белки = безопасно. Тишина = Одичавший рядом | Ждёт, когда хищник уйдёт (звук шагов удаляется) |
| Проход через Болото | Лягушки квакают = иди. Замолкают = стой, жди | Ждёт 10–15 сек, пока Громила пройдёт. Идёт дальше |
| Ночёвка в Лесу | Светляки + тишина = безопасное место. Вой вдалеке = волки вышли | Разводит костёр в месте, где нет звуков хищников |
| Торговля с дрягвой | Гул голосов, треск костра = лагерь близко | Идёт на звук |

Мирный игрок **читает индикаторы раньше** боевого: он слушает биом постоянно, а не только перед боем.

## 7. Обучение игрока: аудио-кривая

Игрок учится «читать ушами» постепенно, от простого к сложному:

```
Час 0–1:  ПЕРВЫЙ ЗВУК. Волк рычит перед прыжком.
          Игрок СЛЫШИТ угрозу до того, как видит.
          Урок: «Звук = телеграф. Реагируй на звук, а не на картинку.»

Час 1–3:  ТИШИНА КАК СИГНАЛ. Птицы замолкают.
          Игрок замечает: «Тихо... что-то не так.»
          Урок: «Отсутствие звука — тоже информация.»

Час 3–5:  ЗВУК ОКРУЖЕНИЯ. Бульканье = утопец у воды.
          Треск = падающее дерево. Вой = волки близко.
          Урок: «Звук привязан к месту. Учи звуковой ландшафт.»

Час 5–15: ИНДИКАТОРЫ. Лягушки замолкают = Громила рядом.
          Цапля кричит = кто-то есть. Ворон каркает = бой/труп.
          Урок: «Живность — твой радар. Слушай её.»

Час 15–30: БОЖЕСТВЕННЫЙ СЛОЙ. Шёпот, гром, треск льда.
           Музыка земли, вой Белого Волка.
           Урок: «Боги говорят через мир. Слушай не только ушами.»
```

## 8. Технические пометки (для звукорежиссёра)

> ⚠️ Это НЕ техническое задание. Это дизайн-помета: что важно для реализации.

### 8.1. Типы звуков по реализации

| Тип | Природа | Пример | Частота срабатывания |
|---|---|---|---|
| **One-shot** | Короткий звук-событие. Проигрывается один раз. | Телеграф атаки, треск дерева, удар молнии | По событию |
| **Loop** | Зацикленный фоновый звук. Громкость меняется плавно. | Ветер, дождь, комариный звон, дыхание | Постоянно |
| **Stinger** | Музыкальный акцент поверх фона. Не событие — настроение. | Нарастание напряжения в чаще, затихание перед атакой босса | 1 раз в 60–120 сек |
| **Ambient** | Пассивный шум места. Меняется с градиентом биома. | Птицы в Лугах, тишина в Сердце Болота | Постоянно, 3–5 слоёв |
| **Voice** | Голос NPC/существа. | Голос Лешего, плач Водяницы, шёпот посланников | По событию |

### 8.2. Приоритеты для MVP

| Приоритет | Что | Почему |
|---|---|---|
| **P0** | Аудио-телеграфы всех врагов Tier 1 (волк, утопец, кабан) | Базовая читаемость боя. Без звука — половина телеграфа |
| **P1** | Биомные звуковые профили (птицы, лягушки, тишина) | «Говорящий визуал» → «говорящий звук» (B6) |

## 9. Чего НЕ должно быть (аудитория 13–14, B2)

| ❌ Запрещено | ✅ Вместо этого |
|---|---|
| Резкие скримеры (внезапный громкий крик за спиной) | Плавное нарастание громкости. Звук телеграфирован визуально (враг открыл пасть — сейчас зарычит) |
| Страшные голоса, шёпоты на грани слышимости без контекста | Шёпот посланников — только для Олега, как информация, не хоррор. Голос Водяницы: «Помоги...» — предупреждение о ловушке, не страшилка |
| Инфразвук / низкие частоты, вызывающие тревогу (как в хоррорах) | Низкие частоты — только как бас удара. Утробный звук Громилы = информация о массе врага, не «страх» |
| Детский плач, крики боли, натуралистичные звуки смерти | Враг умирает: хрип, падение, тишина. Без детализации |
| Звуки расчленения, хруст костей, чавканье | Звук удара = глухой/звонкий удар, свист оружия. При попадании — короткий хруст, не анатомическая детализация |
| Звуковой хаос: 5+ звуков одновременно | Правило трёх слоёв и пауз (§5) |
| Громкая музыка, заглушающая индикаторы | Музыка — минималистичная, фоновая. Громкость музыки −40% при активных телеграфах |
