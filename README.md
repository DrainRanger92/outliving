# Outliving

**Воксельная Action-RPG в сеттинге тёмного славянского фэнтези.**

По мотивам цикла «Трое из Леса» Юрия Никитина.
Аудитория 13–14 лет. Solo-first + сессионный кооп.

Ты — невр, изгнанный из Леса. Ты выходишь на опушку и видишь Луга.
Впереди — мир, который тебя не ждёт. Болота с нечистью, тёмные чащи,
забытые алтари, учителя, которым есть чему научить.
Твой путь — не меню прокачки, а география: хочешь силу — иди в опасность.

## Философия

- **Честная суровость.** Враг читаем — и ты читаем. Никакого обмана механик.
- **Прогрессия = география.** Сила находится на карте. Иди туда, где она.
- **Пассивные состояния, не кнопки.** Ты входишь в Ярость / Знание / Темп
  через действия, а не нажатия. Одна трансформация — смена формы, не спелл.
- **Инструменты, а не предписание.** Хочешь — руби нечисть. Хочешь — пеки хлеб
  и торгуй с караванами. Мирный путь — полноценная роль.
- **Тёмное, но не гримдарк.** Сурово, но с иронией Никитина.

## Репозиторий

Этот репозиторий — **дизайн-репозиторий**, не код. Здесь живут:
- `docs/` — дизайн-документы (GDD, бой, биомы, прогрессия)
- `design/` — артефакты AI-воркера
- `.harness/` — правила для AI-агентов

Работа строится через GitHub Issues с лейблами. AI game designer worker
берёт Issue → исследует → проектирует → выкатывает PR с дизайн-документом.
